MDX is Markdown with JSX. Ordinary prose stays simple, and you can drop in a
component wherever Markdown runs out of expressiveness.

## Markdown first

Headings, lists, tables, links, and fenced code blocks all work as usual. The
outline on the right is generated from your headings, so structure longer posts
with `##` and `###` sections.

## Global components

The Fumandocs MDX components are registered globally, so there is nothing to
import:

<Callout title="Tip" type="tip">
  Callouts, cards, code blocks, and headings all come from `fumandocs-ui/mdx`.
</Callout>

## Mantine components

Import Mantine components at the top of the file and use them like any other JSX
element:

<Alert title="Mantine works inside posts" color="blue">
  The same components used across the site are available here.
</Alert>

<Group mt="md">
  <Button>Primary</Button>
  <Button variant="default">Default</Button>
</Group>

```mdx
import { Alert, Button, Group } from "@mantine/core";

<Group>
  <Button>Primary</Button>
  <Button variant="default">Default</Button>
</Group>
```

## Code blocks

Fenced code blocks are highlighted with Shiki using the GitHub light and dark
themes:

```ts
export function greeting(name: string): string {
  return `Hello, ${name}!`;
}
```

## Lists and tables

- Posts are sorted by `date`, newest first.
- Drafts stay out of production builds.
- Tags are displayed in the list and on the post page.

| Field         | Required | Notes                     |
| ------------- | -------- | ------------------------- |
| `title`       | yes      | Shown in the list         |
| `description` | yes      | Used for metadata         |
| `date`        | yes      | Sorted newest first       |
| `tags`        | no       | Defaults to an empty list |
| `draft`       | no       | Hidden in production      |

## Links and images

Link to other pages with root-relative URLs such as
[Getting started](/docs/getting-started), or to external sites like
[Fumadocs](https://fumadocs.dev).

Images work like normal Markdown. Put the file under `public/` and reference it
from the post:

```mdx
![A screenshot](/screenshot.png)
```

## Keep the outline useful

The table of contents only includes headings, so avoid using `##` for decorative
text. Short paragraphs and one idea per section make long posts easier to scan.
