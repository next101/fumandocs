Welcome to your new blog. Posts are plain MDX files in `content/blog`, and the
list you just came from is built at request time from their frontmatter.

## Frontmatter

Every post needs a `title`, a `description`, and a `date`. Tags are optional.

```yaml
---
title: Hello, world
description: The first post on a blog scaffolded with create-fumandocs.
date: 2026-10-31
tags: ["meta", "nextjs"]
---
```

Add `draft: true` to keep a post out of production builds while still seeing it
in `next dev`.

## What's next

Create a file in `content/blog`, give it frontmatter, and it appears in the list
automatically. No registration or index file to maintain.

Post pages reuse the docs layout, so you get the "On this page" rail, "Copy
Markdown", and the "Open in…" menu for free. The post list is also available as
RSS at `/blog/rss.xml`.
