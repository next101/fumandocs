Welcome to your new blog. Posts are plain MDX files in `content/blog`, and the
list you came from is generated from their frontmatter.

<Callout type="info" title="No CMS required">
  Add a file, write MDX, and the post appears. Drafts stay out of production
  builds until you are ready.
</Callout>

## How posts are discovered

Every `.mdx` file under `content/blog` becomes a page. The loader reads the
frontmatter, sorts posts by `date`, and builds the index and RSS feed. There is
no registry or index file to update.

```text
content/blog/
  hello-world.mdx
  writing-in-mdx.mdx
```

## Frontmatter

Every post needs a `title`, a `description`, and a `date`. Tags are optional.

```yaml
---
title: Hello, world
description: The first post on a blog scaffolded with create-fumandocs.
date: 2026-10-31
tags: ["meta", "nextjs"]
draft: false
---
```

| Field         | Required | Notes                         |
| ------------- | -------- | ----------------------------- |
| `title`       | yes      | Shown in the list and title   |
| `description` | yes      | Used in metadata and the list |
| `date`        | yes      | Sorts newest first            |
| `tags`        | no       | Shown as badges               |
| `draft`       | no       | Hidden in production builds   |

Dates are coerced to `Date` objects, so `2026-10-31` and ISO timestamps both
work.

## Drafts

Set `draft: true` and the post is visible in `next dev` but excluded from the
production build. The index, sitemap, RSS feed, and Markdown route all skip it.

## Reading and sharing

Each post reuses the docs reading layout:

- The "On this page" rail is built from your headings.
- "Copy Markdown" fetches the processed post from `/llms.mdx/blog/...`.
- The "Open" menu links to the post in ChatGPT, Claude, Cursor, and Scira.
- The list is available as RSS at `/blog/rss.xml`.
