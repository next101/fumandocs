Every page renders inside Mantine's provider, so you can import components from
`@mantine/core` and use them directly in MDX. Fumandocs also registers a few
helpers — callouts, cards, and heading anchors — globally.

## Styling

Use Mantine props and CSS variables such as `var(--mantine-color-dimmed)` and
`var(--mantine-spacing-md)` instead of utility classes. The site has no Tailwind
dependency, and both light and dark schemes come from the same tokens.
