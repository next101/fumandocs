This starter pairs the [Fumadocs](https://fumadocs.dev) content engine with
[Mantine](https://mantine.dev) as the UI layer. Pages are MDX files with
frontmatter; navigation, search, and the table of contents are generated from
them.

## What's in the box

- **Docs layout** with a collapsible sidebar, mobile drawer, search, and TOC.
- **Mantine components** available directly in MDX.
- **Fumandocs helpers** such as callouts and cards, registered globally.
- **Search** at `/api/search`, powered by the same content source.
- **Markdown export** at `/llms.mdx/docs/.../content.md`.

## Project structure

```text
content/
  docs/
    index.mdx        # this page
    components.mdx   # component examples
    meta.json        # navigation order
lib/
  source.ts          # Fumadocs loader for /docs
app/
  docs/
    layout.tsx       # DocsLayout and sidebar title
    [[...slug]]/
      page.tsx       # renders each MDX page
```

## Write a page

Create an `.mdx` file under `content/docs`:

```mdx
---
title: Configuration
description: Site URL, repository links, and theme
---

Your content starts here.
```

`title` is required; `description` is optional but recommended for metadata and
search results. Headings become table-of-contents entries automatically.

## Navigation

`content/docs/meta.json` controls the sidebar order. List page slugs in the
order you want them:

```json
{
  "title": "Documentation",
  "pages": ["index", "components"]
}
```

## Preview and build

```bash
pnpm dev     # http://localhost:3000/docs
pnpm build   # production build
pnpm start   # serve the build
```
